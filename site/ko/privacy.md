# 개인정보 처리방침

[English](/privacy)

이 방침은 `app.omagari.org`의 **호스티드 Omagari 서버**에만 적용돼요. 팀이 직접 서버를 운영하면 거기에 뭘 저장할지는 그 팀의 운영자가 정하고, 이 방침은 적용되지 않아요.

최종 수정: 2026-11-21 · 시행일: 2026-11-21

## 1. 운영자와 개인정보 보호책임자

호스티드 서버 운영자이자 개인정보 보호책임자는 백찬(Chan Baek)예요. 연락처: `privacy@omagari.org`.

## 2. 처리하는 개인정보 항목과 목적

팀원끼리 누가 뭘 하는지 보여 주고 대화할 수 있게 하는 데 필요한 것만 저장해요. 광고에 쓰지 않고, 팔지 않아요.

| 항목 | 목적 |
| --- | --- |
| GitHub 로그인 이름, 프로필 이름 | 로그인, 팀에 나를 보여 주기 |
| GitHub 토큰(액세스·리프레시), **암호화해서 저장** | 내 대신 GitHub에 묻기: push 권한, 결정 PR, 이슈, 라벨, 머지. 토큰은 서버가 가지고 있고 내 컴퓨터에는 오지 않아요 |
| 접근 요청: 계정, 요청한 사람, 결과, 처리한 사람 | 운영자가 계정을 승인하기 |
| 내가 push할 수 있는 repo, 공유한 repo | 내 repo만 보여 주기 |
| 작업: 브랜치 이름, 바뀐 파일 경로, 공유 수준 `full`이면 바뀐 파일의 **내용** | 팀원 작업끼리 충돌 찾기, 머지 검사 돌리기 |
| 한 줄 상태, 자리 상태, 상태 메시지와 이모지, 설정 | 팀에 보여 주기, 기기끼리 설정 맞추기 |
| 채팅, Q&A, 포럼 글, 반응, 토의 패치(diff, 최대 64KB) | 워크스페이스의 대화와 결정 |
| 앱을 연 날(워크스페이스별 로그인과 날짜) | 쓰는 사람 수 세기 |
| GIF 검색어 | 내 대신 GIPHY에서 찾기(5항 참고) |

이메일, 전화번호, 결제 정보는 받지 않아요. 서버는 추적 쿠키를 쓰지 않아요. 웹 앱은 로그인과 몇 가지 선택을 브라우저의 로컬 저장소에 둬요.

## 3. 처리 및 보유 기간

- **바뀐 파일 내용, 토의 패치**: 브랜치가 사라지거나 **30일** 동안 바뀌지 않으면 지워요.
- **채팅, Q&A, 글**: 지울 때까지, 또는 워크스페이스·repo·계정을 지울 때까지 보관해요.
- **토큰과 세션**: 로그아웃하거나 계정을 지울 때까지예요. GitHub 토큰은 8시간 뒤 만료돼서 갱신하고, 리프레시 토큰은 최대 6개월이에요.
- **일별 방문 기록, 접근 요청**: 12개월 동안 두고, 그 전에 워크스페이스나 계정을 지우면 그때 지워요.
- **백업**: 호스트의 디스크가 일별 스냅샷을 5일 보관해요. 지운 데이터는 5일 안에 백업에서도 사라져요. 호스트 밖에 백업을 두게 되면 먼저 이 방침을 고쳐요. 지운 데이터를 되살리려고 백업을 복원하진 않아요. 장애 복구 때문에 복원하면, 지웠던 걸 다시 지워요.

## <a id="delete"></a>4. 파기 절차와 방법 (직접 지우기)

지우려고 메일을 보낼 필요가 없어요.

- **내 계정**(설정): 내 토큰, 세션, 프로필, 자리 상태, 작업, 설정이 지워져요. 예전 메시지는 남고 "삭제된 멤버"로 보여서 대화가 계속 읽혀요. 메시지도 지우고 싶으면 메일을 보내 주세요.
- **repo 데이터**: 그 repo의 GitHub Admin이 repo를 빼고 데이터를 지워요.
- **워크스페이스**: 안의 모든 repo의 GitHub Admin인 사람이 워크스페이스를 지워요. (Omagari는 조직 역할을 읽지 않아요.)
- **바뀐 파일 내용과 패치**는 30일 뒤 저절로도 지워져요(3항).

지운 행은 표시만 하는 게 아니라 데이터베이스 파일에서 덮어써서 지워요. GitHub App을 빼려면 GitHub 설정에서 하면 되고, 그러면 새 데이터가 들어오지 않아요.

## 5. 제3자 제공과 처리 위탁

Omagari를 돌리려고 아래 서비스를 써요. 저희 대신 처리하거나, 그 기능을 쓰기 때문에 받아요.

| 누구 | 무엇을 위해 | 받는 정보 | 어디 |
| --- | --- | --- | --- |
| Fly.io | 서버와 디스크 운영 | 서버에 저장된 모든 것 | 일본 도쿄(`nrt`) |
| GitHub | 로그인과 repo | 서버가 묻는 것. GitHub는 내가 거기서 하는 일을 알아요 | 미국 등 |
| GIPHY | GIF 검색과 GIF 이미지 | 검색어(저희 서버가 저희 키로 보내요). 이미지는 브라우저가 GIPHY에서 받아서 GIPHY도 일반 웹사이트처럼 그 요청을 봐요 | 미국 |

법이 요구하지 않는 한 그 밖의 누구에게도 주지 않아요. 같은 워크스페이스 사람들은 내가 공유한 걸 봐요. 그게 서비스의 목적이에요.

**국외 이전.** 서버와 백업은 일본에 있고, GitHub와 GIPHY는 미국 등에 있어요. 호스티드 서버를 쓰면 이에 동의하는 거예요. 원하지 않으면 호스티드 서버를 쓰지 말고 직접 서버를 운영하세요.

## 6. 정보주체의 권리와 행사 방법

내 개인정보를 보거나, 고치거나, 지우거나, 처리를 멈춰 달라고 할 수 있고, 동의를 거둘 수 있어요. 4항의 버튼이나 `privacy@omagari.org`로 요청하세요. 10일 안에 답해요. EU에 살면 GDPR이 주는 권리도 있고, 감독기관에 민원을 낼 수 있어요. 개인정보보호위원회(privacy.go.kr, 182)에도 문의할 수 있어요.

## 7. 안전성 확보 조치

GitHub 토큰은 암호화해서 저장하고, 그 키는 백업과 따로 둬요. 서버는 HTTPS만 써요. 데이터베이스와 백업은 공개하지 않고, 접근은 운영자로 제한해요. 장애와 유출에 대한 대응 계획이 글로 있어요. 개인정보가 유출되면 법이 정한 기한 안에 영향받은 워크스페이스의 관리자와 관계 기관에 알려요.

## 8. 아동

개발자를 위한 서비스이고 만 14세 미만 아동을 위한 게 아니에요. 아동의 정보를 알면서 모으지 않아요.

## 9. 방침이 바뀔 때

바뀌면 새 날짜와 함께 여기에 올리고, 중요하면 웹 앱에서도 알려요. 옛 버전은 저장소 기록에 있어요.
