# 세션 시작 훅은 누가 무엇을 하는지까지 넣는다

Room의 세션 시작 훅은 밀린 편지함과 "누가 와 있다"는 이름 한 줄만 넣고, 누가 무엇을 하는지는 에이전트가 따로 도구를 불러야 본다. Omagari는 구현 4장대로 지금 팀의 작업을 상태 한 줄로 요약해 넣는다. 계획을 세우기 전에, 에이전트가 무엇을 불러야 할지 모르는 상태에서도 주변을 알게 하려는 것이다.

## Consequences

- 사람과 작업이 많으면 길어진다. 훅이 넣는 글은 Claude Code에서 10,000자를 넘으면 파일 경로와 앞 2,000자로 바뀌므로([hooks](https://code.claude.com/docs/en/hooks)) 그 안에서 자른다. 내 작업과 같은 파일을 건드리는 작업을 먼저 넣고, 나머지는 작업마다 한 줄, 넘치면 `omagari status`를 가리키고 끊는다.
