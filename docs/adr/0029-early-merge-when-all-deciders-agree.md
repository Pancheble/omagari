# 결정자가 모두 동의하면 이의 창을 일찍 닫고 머지한다

ADR-0025의 결정 PR에는 "이의"만 있고, "하루" 창은 끝까지 기다려야 머지된다. 시안을 보고 주인이 바로 머지는 못하느냐고 물었다(2026-11-13). 결정 상태 띠에 "동의"를 둔다. 결정자(그 포스트에서 말한 멤버)가 모두 동의하면 창을 일찍 닫고 바로 머지한다. 정리한 사람은 연 것으로 동의한 셈이다. 아무도 누르지 않으면 지금처럼 창이 닫힐 때 머지한다.

원칙 4("관문 대신 이의 창")는 그대로다. 동의는 누르지 않아도 되는 지름길이고, 확정의 조건이 아니다.

## Considered Options

- **이의만 둔다**(ADR-0025 그대로): 모두가 이미 같은 말을 했는데도 하루를 기다려야 한다. 되돌리기 쉬운 것은 처음에 "바로"를 고르면 되지만, 하루로 연 뒤에는 앞당길 길이 없다.
- **아무 멤버 한 명의 동의로 머지**: 결정자 아닌 사람이 대신 확정하게 된다.

## Consequences

- 결정자가 아닌 멤버는 "이의"만 본다. 동의가 다 모이기 전까지 누구나 이의를 낼 수 있고, 이의가 걸리면 동의가 다 모여도 머지하지 않는다.
- GitHub 규칙(리뷰 필수, 검사)은 그대로 따른다. 모두 동의해도 GitHub이 막으면 "머지 막힘"이다.
- 동의는 공간에서만 낸다. GitHub의 승인 리뷰를 동의로 셀지는 정하지 않았다.
