# 합친 것만 깨질 때 확인이고, 통과하면 추정 알림을 닫는다

합쳐 돌려 보기의 판정은 넷이다: 통과, 깨짐, 가릴 수 없음, 돌리지 못함. 합친 것이 깨지면 러너는 내 작업만, 상대 작업만으로 같은 검사 명령을 한 번씩 더 돌린다. 둘 다 통과할 때만 "깨짐"이고, 그때 간접 충돌이 확인된 것이다. 어느 한쪽이 혼자서도 깨지면 "가릴 수 없음"이다. 통과하면 추정 알림을 풀림으로 닫는다(2026-11-13 주인 확인, `docs/stage3-questions.md` Q1·Q3, A7·A8).

관측은 커밋하지 않은 것까지 올리므로(ADR-0007) 합치는 것은 고치는 중인 코드다. 고치는 중인 코드는 혼자서도 자주 깨진다. 따로 돌려 보지 않으면 그것이 "합치면 깨진다"로 잘못 선다. Crystal도 각자의 상태(빌드 실패, 테스트 실패, OK)를 합친 결과와 따로 본다. "둘 다 혼자서는 통과할 때만 확인"이라는 규칙은 거기서 끌어낸 것이다.

- **통과**: 검사 명령이 0으로 끝났다. 추정 알림에 "합쳐 돌려 보니 통과"를 적고 풀림으로 닫는다. 통과한 쌍은 내용이 바뀌어도, 다시 돌린 판정이 나올 때까지 알림을 다시 세우지 않는다. 다시 돌려 깨지면 확인된 새 알림이, 가릴 수 없거나 돌리지 못하면 추정인 새 알림이 선다. 알림이 돌릴 때마다 섰다 닫혔다 하지 않게 하려는 것이다.
- **깨짐**: 합친 것은 깨지고 두 작업은 따로 통과한다. 새 알림을 만들지 않고 같은 알림(같은 포스트)을 "확인됨"으로 바꾸고, 두 작업의 편지함에 다시 넣는다.
- **가릴 수 없음**: 합친 것이 깨지는데 어느 한쪽이 혼자서도 깨진다. 알림은 추정으로 남는다.
- **돌리지 못함**: 줄이 부딪혀 합쳐지지 않는다, 검사 명령이 없다, 샌드박스를 쓸 수 없다, 시간이나 출력의 상한에서 끊겼다. 끊긴 것은 통과가 아니다. 상한은 Room의 값(5분, 출력 4MB)에서 시작한다.
- 상대의 내용이 빠진 파일(공유 수준, 크기)이 있으면 그 파일 없이 돌리고 판정에 빠진 파일을 적는다. 이런 판정은 깨져도 확인으로 치지 않고, 통과해도 알림을 닫지 않는다.
- 통과와 깨짐은 종료 코드로만 가린다. Room은 출력에서 테스트 요약도 읽어, 요약이 없으면 통과로 치지 않는다. 테스트 도구마다 꼴이 달라 넣지 않았다.

## Considered Options

- **합친 것만 돌린다**: 한 번만 돌려 싸지만, 고치는 중이라 깨진 것이 모두 "확인"으로 선다. 확인은 4단계에서 토론을 저절로 여는 조건이라(원칙 6) 틀리면 비용이 크다.
- **통과해도 열어 둔다**: 배지만 "통과"로 바꾸고 사람이 닫는다. 추정은 이름 매칭이라 오탐이 섞이고(ADR-0023), 틀린 알림이 쌓이는 것은 기획 8장의 리스크다.

## Consequences

- 깨질 때마다 세 번 돌린다. 내 작업만 돌린 판정은 내용이 같으면 다시 쓴다.
- 검사 명령이 그 호출을 덮지 않으면, 통과로 닫힌 알림이 실제로는 깨질 수 있다. 어떤 명령으로 통과했는지를 포스트에 남긴다.
- 샌드박스에서 돌지 못하는 검사 명령(바깥 네트워크, Docker)은 혼자 돌린 것도 깨져 "가릴 수 없음"이 된다. 거짓 "깨짐"은 나지 않는다(ADR-0033).
