# 관측은 파일 내용을 보내지 않는다

Room은 팀 방에서 바뀐 파일의 전체 내용을 기본으로 서버에 올리고(공유 수준 full, 줄이면 declared나 intent), 그 내용으로 남의 선점 줄 번호를 내 사본에 맞추고 합쳐 보기를 한다. Omagari는 구현 문서 11장대로 바뀐 파일 목록과 정의 줄만 보낸다. 푸시되지 않은 남의 코드는 그 사람의 기기를 떠나지 않는다(구현 6장). 서버가 남의 코드를 들고 있지 않으면 서버가 뚫려도 잃을 코드가 없고, 처음 연결할 때 "무엇이 나가는지"를 한 줄로 말할 수 있다.

## Consequences

- 겹침은 파일 단위로만 안다. 같은 파일의 다른 함수를 고쳐도 직접 충돌로 보인다. 정밀도는 구현 12장의 지표로 잰다.
- 남의 줄 번호를 내 사본으로 옮길 수 없어서 선점은 경로 단위가 된다(ADR-0004).
- 합쳐 돌려 보기는 푸시된 브랜치나 내 로컬 작업으로만 한다(구현 6장 그대로).
- 정의 줄도 코드의 일부라 밖으로 나간다. 그래서 늘 빼는 것을 둔다: gitignore된 파일, 추적되더라도 `.env`와 `.env.*`(`.env.example`은 남긴다). 이 목록은 Room의 기본 제외를 따랐다. 변수와 상수는 값이 비밀일 수 있어 이름만 보낸다.
