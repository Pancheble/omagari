# 묻기는 받는 쪽 스위치로 동의하고, 기본은 켜짐이다

`omagari ask`(묻기)는 내 에이전트가 다른 멤버의 에이전트에게 묻는 것이라, 상대의 에이전트를 상대의 사용량으로 부른다. "에이전트는 주인만 부를 수 있다"(구현 1장)와 어긋나서 받는 쪽이 동의하는 방식을 2단계에서 먼저 정하기로 했다(ADR-0009). Room에는 동의 장치가 없다. 받는 사람의 작업 세션이 편지함으로 받아 직접 답하고, 방에 들어온 것이 곧 동의다.

멤버마다 "내 에이전트가 남의 질문에 답한다" 스위치를 둔다. 기본은 켜짐이고, 주인이 언제든 끈다. 4단계의 자동 참여 스위치(구현 7장)도 이 스위치를 함께 쓴다. 두세 명 팀에서 기본이 꺼짐이면 아무도 켜지 않아 묻기가 돌지 않는다(2026-11-12 주인 확인, `docs/stage2-questions.md` Q1).

## Considered Options

- **묻는 쪽 비용**: 묻는 사람의 러너가 상대의 관측을 기준 커밋 위에 얹은 임시 트리에서 자기 실행기로 답한다. 동의가 필요 없지만 상대의 공유 수준이 full이 아니면 모르고, "상대 에이전트에게 묻는다"가 아니게 된다.
- **질문마다 승인**: 받는 사람이 허락해야 러너가 돈다. 묻는 에이전트가 사람을 기다리느라 묻기의 쓸모가 줄어든다.

## Consequences

- 받는 쪽 러너가 오프라인이면 질문을 남겨 두었다가 러너가 붙을 때 답한다. 14일이 지나면 만료한다(Room의 편지함). 묻는 쪽에는 바로 "오프라인이라 돌아오면 답한다"를 돌려준다. 꺼져 있을 때 대행이 답하는 것(구현 4장)은 4단계다.
- 스위치가 꺼진 멤버에게 물으면 바로 "받지 않는다"를 돌려준다.
- 구현 13장의 "자동 토론 참여 스위치의 기본값"도 켜짐으로 닫힌다.
