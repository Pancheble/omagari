# 상태 한 줄은 에이전트가 직접 쓰고, 작업이 끝나면 사라진다

Room에는 상태를 쓰는 도구가 없다. 범위 선언, 선점, 기다리기, 끝내기를 하면 그때마다 상태가 덮어써진다. Omagari는 에이전트가 직접 쓴다(구현 5장). 무슨 일을 하는 중인지는 그 일을 하는 에이전트만 알고, 1단계에는 상태를 대신 만들어 줄 선점이 없기 때문이다(ADR-0009). 직접 쓰면 일이 끝난 뒤에도 "~하는 중"이 남으므로 수명을 정한다.

- 에이전트는 작업을 시작할 때, 방향이 바뀔 때, 끝낼 때 쓴다. 끝낼 때는 "끝: <요약>"으로 쓴다.
- 보이는 줄은 이 순서로 고른다: 오프라인 → 에이전트가 쓴 줄 → 초안 PR 제목 → 고치는 파일 → 바뀐 것이 없으면 줄 없음.
- 에이전트가 쓴 줄 옆에는 쓴 시각을 붙인다.
- 그 브랜치가 머지되거나, 관측된 변경이 있다가 0이 되면 에이전트가 쓴 줄을 지운다.

## Consequences

- 에이전트가 쓰기를 잊으면 줄이 낡는다. 쓴 시각이 그것을 드러내고, 지우는 규칙이 끝난 작업의 줄을 치운다.
- 작업을 막 시작해 아직 바뀐 것이 없을 때 쓴 줄은 지우지 않는다. 그래서 지우는 조건이 "변경이 0"이 아니라 "있다가 0이 됨"이다.
