# 상황의 단위는 세션이 아니라 작업이다

Room의 참가자는 에이전트 세션 하나하나다. 같은 사람이 세션을 여럿 띄우면 `rohanz+claude` 같은 꼬리표로 다른 참가자가 되고, 같은 체크아웃의 세션 여럿은 한 세션만 관측을 올리도록 임대(lease)를 주고받는다. Omagari는 사이드바에 사람마다 에이전트 하나를 두고(기획 6장), 상태 한 줄과 관측은 작업(사람 + 브랜치)마다 하나로 둔다. 러너가 폴더마다 하나라 관측하는 쪽이 늘 하나이므로 임대가 필요 없다. 등록한 폴더의 연결된 워크트리(`git worktree list`)도 같은 러너가 관측하고, 워크트리마다의 브랜치가 각각 작업이 된다.

## Consequences

- 같은 브랜치에서 작업 세션 둘이 상태 한 줄을 쓰면 나중에 쓴 것이 남는다.
- 편지함의 주인을 사람으로 할지 작업으로 할지는 이 결정 위에서 따로 정한다.
