# 1단계에서 2단계로 넘어가는 인원 조건을 없앤다

구현 문서 1장은 "각 단계는 앞 단계가 쓰일 때만 넘어간다"고 하고, 1단계("공간")에서 2단계로 넘어가는 조건을 "두세 명이 매일 들어온다"로 두었다. PRD #3도 다 만들었을 때 확인할 것을 이것 하나로 두었고, 그 수를 세는 길도 만들었다(ADR-0018). 2026-11-12 마일스톤 "1 공간"의 이슈를 다 닫은 뒤, 주인은 이 조건을 없앴다. 주인의 말 그대로: "저 두새명 씹어버리고 ㄱㄱ 뭐가 있어야지 쓰지", 이어서 "그 마일스톤은 남기되 그 인원으로 넘어가는건 없애자 ㅇㅇ 필요없음". 공간만으로는 사람이 매일 들어올 까닭이 모자라고, 부딪힘 알림에서 결정까지 가는 흐름처럼 쓸 거리가 있어야 들어온다는 판단이다.

## Consequences

- 단계 표의 1단계 줄에는 넘어가는 조건이 없다. PRD #3의 "다 만들었을 때 확인할 것은 하나다: 두세 명이 매일 들어오는가"도 더는 확인하지 않는다.
- 단계와 마일스톤("1 공간"부터 "4 토론"까지)은 그대로 둔다.
- 다른 단계의 넘어가는 조건(2단계의 "알림에서 결정까지 이어진 사례가 나온다" 등)은 이 결정이 건드리지 않는다. 남길지는 2단계 문답에서 정한다(`docs/stage2-questions.md`).
- 지표(ADR-0018, `omagari metrics`)는 그대로 둔다. 어떻게 할지는 2단계 문답에서 정한다.
- ADR-0012와 ADR-0019는 "1단계는 두세 명이 매일 들어오는지를 재는 단계"를 근거로 설치 묶음과 릴리즈 자동화를 미뤘다. 이 결정으로 그것들이 당겨지지는 않는다.
