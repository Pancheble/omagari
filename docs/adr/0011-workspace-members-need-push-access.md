# 워크스페이스에는 그 레포에 push 권한이 있는 계정만 들어온다

관측이 작업 중인 파일 내용을 서버에 올리므로(ADR-0007) 워크스페이스의 멤버는 서로의 푸시 전 코드를 본다. 그래서 따로 초대 화면을 두지 않고, GitHub 로그인 때 그 레포의 push 권한으로 멤버인지 정한다. Room과 같은 규칙이다.

## Consequences

- push 권한이 없는 사람(읽기 권한만 있는 협업자, 코드를 고치지 않는 팀원)은 지금은 들어올 수 없다. 그런 멤버의 자격은 나중에 정한다. 미정이다(구현 13장).
- 권한을 잃은 사람을 내보내려면 권한을 다시 확인해야 한다. Room은 10분마다 다시 확인한다. 그 값에서 시작한다.
