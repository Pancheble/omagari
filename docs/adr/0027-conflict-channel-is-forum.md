# 부딪힘은 포럼 채널이고, 알림 하나가 포스트 하나다

2단계 문답 Q3은 알림에 포스트를 달되 "포럼 채널은 만들지 않는다"였다. 부딪힘은 보통 채팅 채널이라 알림 줄과 사람의 말이 섞이고, 포스트는 알림 줄의 "이야기하기"로 열었다. 시안(이슈 #89)을 보고 주인이 Discord의 포럼처럼 가자고 했다(2026-11-13). 부딪힘은 포럼 채널이 된다. Omagari가 알림 하나를 포스트 하나로 올리고, 사람은 포럼에서 채팅하지 않고 포스트 안에서만 이야기한다. 화면은 `DESIGN.md`의 "부딪힘 포럼"과 "포스트"(시안 14-A)다.

## Considered Options

- **채팅 채널의 알림 줄**(Q3-A 그대로): 새 채널 종류가 없다. 알림이 늘면 줄과 말이 섞이고, 열린 것과 풀린 것을 가려 볼 수 없다.

## Consequences

- 채널에 종류가 생긴다(채팅, 포럼). 포럼 자체에는 글을 쓸 수 없다. 포스트는 알림이 올라올 때 생긴다(지금 서버는 처음 열 때 만든다, PR #96). 포럼 목록은 포스트마다 종류, 제목, 마지막 글, 글 수, 시각을 받아야 한다. 계약이 바뀌므로 `CONTRACT_VERSION`이 오른다. #89를 시작하기 전에 이 일을 서버 이슈로 떼거나 #89에 넣는다.
- 문답 Q2의 "알림 채널 바꾸기"는 설정 창의 "알림을 올릴 포럼"이 되고, 포럼 채널만 고를 수 있다.
- 사람이 포럼 채널을 따로 만들 수 있게 할지는 정하지 않았다. 지금 포럼 채널은 부딪힘 하나다.
