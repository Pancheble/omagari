# 결정을 고쳐 올리면 동의를 지우고 창을 처음부터 다시 연다

ADR-0025와 문답 Q11은 정리한 사람이 결정을 고쳐 같은 PR에 새 커밋으로 올릴 수 있다고만 적었다. 고친 뒤 이미 받은 동의와 흐르던 창을 어떻게 할지는 적지 않았다(#86). 고쳐 올리면 정리한 사람이 아닌 결정자의 동의를 지우고, 창을 지금부터 같은 길이로 다시 연다. 걸린 이의는 그대로 두고, 낸 사람이 읽고 거둔다.

## Considered Options

- **그대로 둔다**: 고치기 전 글에 받은 동의로, 결정자가 읽지 않은 글이 바로 머지될 수 있다. 창이 거의 닫혔으면 고친 글에 이의를 낼 틈도 없다.
- **이의도 지운다**: 고쳤다고 이의가 풀린 것은 아니다. 이의를 거두는 것은 낸 사람만 한다(Q11).

## Consequences

- 고친 결정은 처음 연 결정처럼 다시 동의를 모으거나 창이 닫히기를 기다린다. "바로"로 연 결정은 고쳐도 곧이어 머지한다.
- 결정 상태 띠의 "다시 열림"은 이의가 모두 거둬졌을 때만 쓴다. 고쳐 올린 것은 포스트의 한 줄(`revised`)로 보인다.
