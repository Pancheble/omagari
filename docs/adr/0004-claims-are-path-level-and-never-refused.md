# 선점은 경로 단위이고, 늘 걸리고, 겹쳐도 거절하지 않는다

Room의 선점은 심볼, 줄 범위, 폴더 단위다(새로 만든 파일은 파일 전체). 근처에 아무도 없으면 "필요 없다"며 걸지 않고, 남이 선언한 범위를 덮는 폴더 선점은 거절한다. 줄 번호는 선점한 사람의 사본 내용으로 내 사본에 옮기고, 옮기지 못하면 "대략"이라고 표시한다. Omagari는 구현 4장대로 `omagari claim <경로>`로 파일이나 폴더를 선점한다. 서버에 파일 내용이 없어 줄 번호를 옮길 수 없고(ADR-0001), 작업을 시작할 때 늘 걸어야 나중에 온 사람이 볼 수 있으며, 겹쳐도 막지 않고 양쪽 편지함에 알린다(원칙 4·6: 막지 않고 알린다).

## Consequences

- 같은 파일의 다른 함수를 고치는 두 사람도 겹침 알림을 받는다. 정밀도를 재서(구현 12장) 낮으면 좁힌다.
- 심볼 단위 정보는 선점이 아니라 선점에 붙인 "바꿀 계약"에 심볼 이름으로 남는다.
